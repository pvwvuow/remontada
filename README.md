# رمانتادا — Remontada ⚽

سایت نتایج زنده فوتبال: امتیاز لحظه‌ای، جدول رده‌بندی، آقای گل و اخبار فارسی.

## امکانات

- **نتایج زنده**: بیش از ۷۰ لیگ جهان + لیگ خلیج فارس، لیگ آزادگان — با بروزرسانی خودکار هر ۶۰ ثانیه
- **جدول لیگ‌ها**: لیگ قهرمانان اروپا، پریمیرلیگ، لالیگا، سری‌آ، بوندسلیگا، لیگ ۱ فرانسه و خلیج فارس + آقای گل
- **اخبار فارسی**: تیترهای ESPN، BBC Sport و Sky Sports با ترجمه‌ی خودی به فارسی
- **RTL کامل** با فونت وزیرمتن و تم تیره‌ی اختصاصی

## استک فناوری

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- منبع داده: FotMob (اصلی) + ESPN (پشتیبان) — بدون نیاز به کلید API
- ترجمه‌ی اخبار: z-ai SDK

## اجرا

```bash
bun install
bun run dev
```

## ساختار

```
src/
├── app/
│   ├── api/matches/     # نتایج روزانه (FotMob + فال‌بک ESPN)
│   ├── api/standings/   # جدول رده‌بندی + آقای گل
│   ├── api/news/        # اخبار چندمنبعی + ترجمه فارسی
│   └── page.tsx         # تک‌صفحه‌ای با سه تب
├── components/remontada/  # کامپوننت‌های UI
└── lib/
    ├── fotmob.ts        # لایه داده (fetch + normalize + fallback)
    ├── leagues.ts       # پیکربندی لیگ‌ها + مپینگ فارسی تیم‌ها
    └── cache.ts         # کش درون‌حافظه‌ای TTL
```
